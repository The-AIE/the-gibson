# The Gibson brand kit

## The mark

A G made of two rings around a lit core:

- **Outer ring:** the Gibson, the governance harness.
- **Inner ring (grey):** your coding agents.
- **Amber core:** the model.
- **Aligned gaps at nine o'clock:** the one gated channel to the core. Every path to the model goes through the gate.
- **Crossbar:** makes it a G. It stops short of the core on purpose, so the harness frames the model without touching it.

## Tagline

| Use | Line |
|---|---|
| Primary (stacked lockup, hero) | The governance harness for your coding agents. |
| Short (horizontal lockup, avatars, repo description) | Governance for coding agents. |

## Files

| File | Use |
|---|---|
| `gibson-lockup-stacked.svg` / `-dark.svg` | Primary lockup: README, docs cover, stickers |
| `gibson-lockup-horizontal.svg` / `-dark.svg` | Headers, slides, email signatures |

| `gibson-icon.png` (512), `apple-touch-icon.png` (180), `favicon.ico` (16/32/48) | App and browser icons |
| `gibson-site-logo.png` | Docs site header (`_config.yml`) |
| `gibson-social-preview.png` (1280×640) | GitHub social preview, link cards |
| `gibson-logo-lockup.*`, `gibson-icon.svg` | Kept at their old names so existing links keep working (same art as the stacked lockup and the mark) |

`-dark` files are for dark backgrounds. All lettering is converted to outlines, so no fonts are needed to display the files.

## Color

| Token | Light backgrounds | Dark backgrounds | Role |
|---|---|---|---|
| Ink | `#12151B` | `#EEF0F2` | Outer ring, crossbar, wordmark |
| Harness grey | `#8A93A3` | `#848D9C` | Inner ring only |
| Core amber | `#D9831F` | `#F0A445` | The core only |

Amber means the AI. Keep it to the core and don't use it anywhere else in the mark.

## Rules

- Below 32 px, use `gibson-mark-small`, because the primary strokes get too thin.
- Keep clear space around the mark equal to the core's diameter × 2.
- Don't let the crossbar touch the core, don't close the nine o'clock gaps, and don't recolor the core.
- Don't add gradients, shadows or outlines.

## Lettering

The wordmark is set in Big Shoulders Display SemiBold with wide tracking (OFL). The tagline is JetBrains Mono Medium (OFL). Custom lettering may replace the wordmark later.
