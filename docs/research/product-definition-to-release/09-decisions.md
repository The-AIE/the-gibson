## Reversal criteria

Prefer current artifacts or a third-party toolkit if it achieves equivalent fidelity/usefulness at lower total burden. Narrow integration if a workbench confuses owners or creates competing state. Reconsider a monorepo only when measured coordination cost warrants it. Reject an optional adapter if its benefit fails to offset operational, privacy, recovery or exit cost.
